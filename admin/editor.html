Portfolio Editor (local only)

How to update: 1) Edit any field below. 2) Click Save changes and choose data/content.js in your portfolio folder (replace it). If your browser can't save directly, use Download file instead and copy the file into data/. 3) Open index.html to check. 4) Run your normal update script to publish. This editor lives in admin/, which git ignores, so it is never published.
Lists: boxes marked "one per line" take one item per line. Images: copy the file into assets/ and type its path, for example assets/my_dashboard.jpg.
